# Description Style

This guide standardizes the descriptive copy in `src/data/usajobs-series-descriptions.json` and `src/data/usagov-agency-descriptions.json`.

## Goals

- Make entries easy to scan side by side.
- Keep descriptions factual, useful, and concise.
- Apply Grice's Maxims: enough detail, accurate detail, relevant detail, and clear detail.

## Shared Rules

- Use plain, neutral, third-person language in the present tense.
- Lead with what the thing is or does.
- Prefer one sentence.
- Add a second sentence only when it prevents confusion.
- Keep examples short and only when they help distinguish broad categories.
- Avoid historical setup, marketing language, and direct-address copy.
- Avoid stacked synonym lists when one strong verb will do.
- Standardize punctuation, capitalization, and acronym treatment.

## USAJOBS Series

- Target length: 18 to 32 words.
- Start with `Covers positions...` for professional series.
- Start with `Covers occupations...` for trade, craft, and labor series.
- Name the primary work domain first, then add one clarifying phrase if needed.
- Use `Excluded: ...` only when a boundary case materially improves classification.

## USA.gov Agencies

- Target length: 22 to 40 words.
- Use the pattern `The <Name> <verb> <main mission or responsibility>.`
- Keep acronyms when they already appear in the agency name.
- Describe the institution, not the website, contact channel, or page history.
- Preserve legal-status clarification only when it is essential, such as government-sponsored enterprises that are not federal agencies.
